# 执行栈与其他混淆能力

## 执行栈混淆

Eval Stack Obfus 试图改变 IL 求值栈和临时变量的直接形态，使局部数据流更难分析。官方文档给出 global → assembly → type → method 的 `obfuscationLevel` 规则体系。

但 `3.1.0` 源码存在关键差异：

- `ObfuscationPassType.EvalStackObfus` 枚举存在；
- `EvalStackObfusPass` 实现存在；
- Settings 和规则解析存在；
- `ObfuscatorBuilder` 中添加该 Pass 的代码被注释。

因此通过默认 `FromObfuzSettings` Builder，即使 `EnabledPasses` 包含 EvalStack，也不会实际注册和运行。除非上游版本已恢复注册，或项目自定义 Builder 手动添加，否则应视为“当前默认不可用”。

不要为了启用它直接取消源码注释后发布。应先确认：

- 官方为何关闭；
- 当前 Unity/IL2CPP/HybridCLR 是否存在兼容问题；
- 异常处理、泛型、byref、async/iterator 等 IL 是否覆盖；
- 与 Expr/ControlFlow/Call 的 Pass 顺序是否安全。

## 垃圾代码生成

Garbage Code Generator 目标是降低本 App 与其他 App 的二进制相似度，辅助应对商店相似度检测和静态特征匹配。官方策略包括：

- 独立生成大量消息、配置、UI 风格代码；
- 在正常代码中注入垃圾指令。

当前生成类别：

- Config：仿 Luban 风格配置加载代码；
- UI：UGUI 绑定代码。

计划类别包括 Protocol、Controller 等。

任务字段：

| 字段 | 含义 |
|---|---|
| Code Generation Secret/Random Seed | 生成随机性 |
| Class Namespace/Name Prefix | 生成代码命名 |
| Class Count | 类数量 |
| Method/Field Count Per Class | 每类成员数 |
| Garbage Code Type | 代码模板类别 |
| Output Path | 生成源码目录 |

### 使用边界

- 垃圾代码不会保护真实业务算法，只增加样本噪声和体积。
- 过量生成会延长 C# 编译、IL2CPP 转换和包体构建。
- 若代码模板特征固定，攻击者可自动识别并删除。
- 不应让垃圾代码引用真实业务资源或进入运行热路径。
- 本项目根规范说明当前未使用 Luban；Config 垃圾代码只是仿 Luban 模板，不代表项目应引入 Luban。

## 代码水印

Watermark Pass 向混淆程序集注入可识别特征，用于版权标识和泄漏溯源。官方列出的载体：

- RVA 数据中的水印 Hash 签名；
- 特殊规则的类型、方法和字段；
- 方法体中特定指令序列。

配置：

- `Text`：水印文本；
- `Signature Length`：Hash 签名长度。

水印不是防篡改机制。攻击者可在理解规则后清理或伪造，实际溯源应结合：

- 每渠道/客户独立水印；
- 构建制品哈希；
- 包签名；
- 服务端版本标识；
- 法务与发布记录。

当前工程仍使用默认 `Obfuscated by Obfuz`，不具备区分发布来源的价值。

## Obfuscation Instincts

Instinct 是写在源码中的“提示调用”，Obfuz 在编辑器 Pass 中识别它并提取原始元数据语义。例如：

```csharp
ObfuscationInstincts.RegisterReflectionType<MyType>();
```

混淆时可以记录 `MyType` 的原始全名到运行时 TypeMapper，而无需开发者手写字符串。处理完成后，Instinct 调用可被删除或替换，不承担正常运行时业务逻辑。

它适合：

- 反射类型映射；
- XLua 类型注册；
- 需要把“编译时 Type”关联到“原始名字”的协议。

具体原理见[反射与序列化兼容](./反射与序列化兼容.md)。

## 能力定位

| 能力 | 主要价值 | 是否建议首批启用 |
|---|---|---:|
| Eval Stack | 局部数据流扰动 | 否，当前默认未注册 |
| Garbage Code | 降低二进制相似度 | 否，按发布需求单独评估 |
| Watermark | 版权和渠道溯源 | 可选，但必须使用专用文本 |
| Instinct | 兼容性元数据提示 | 是，按反射/XLua需要使用 |
